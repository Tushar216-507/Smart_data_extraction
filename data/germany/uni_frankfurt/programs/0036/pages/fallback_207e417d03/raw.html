Welcome to DMPE Data and Software Centre

 

The Data and Software Centre lets you download state-wide spatial datasets, geology series map data, resources such as Department of Mines, Petroleum and Exploration (DMPE) software (including user guides and videos where available), and documentation on map services provided by DMPE.

Each dataset compressed file contains the following: 

  • Metadata statement
  • The dataset (unprojected, geographical coordinates based on the 1994 Geocentric Datum of Australia [GDA1994] AND 2020 Geocentric Datum of Australia [GDA2020]).
  • Licence agreements 

To view the metadata statement, select the icon next to the dataset name. 

To facilitate automated downloading of dynamic datasets, the following documents contain URLs to assist in this process. 

URL document - GDA2020


  • Click the "What's new" tab to see new and previous releases.
  • Click the "Datasets [GDA2020]" tab to view datasets available in GDA2020 coordinates.
  • Click the "Datasets [GDA94]" tab to view datasets available in GDA94 coordinates. 
  • Click the "Map services and resources" tab to access a range of available software, map services, and training material. 

Type a keyword in the search tool on the right to search for specific datasets in a specific coordinate system. 

Nightly process to update dynamic datasets is scheduled to be completed by approximately 3am following each business day.

After 31st March 2026, we will only create GDA2020 outputs.

Most GDA94 downloads are now unavailable since 31st March 2026.

 

ESRI will retire ArcMap 10.8.2 on the 1st March 2026.

We will keep creating ESRI layerfiles (lyr) up to 31st March 2026, after this date we will only create ArcGIS Pro layer files (lyrx) for new or updated layers.

What’s changing?
 
On 17th June 2022, the Data and Software Centre is moving to the Cloud which will mean a smoother, faster, productive and more secure service. The URL for DASC will change to https://dasc.dmirs.wa.gov.au  
We recommend you read and follow the below bullet points to ensure the transition is as smooth as possible. 
 

  • Any scripts or processes that have been created to access DASC files via DASC or Geoview will need to be updated with the new URLs.
  • If you have saved a DASC file (even if it is via Geoview) or the DASC homepage as a favourite or shortcut, please resave these links and bookmarks with the new URL so you can always find the pages.
  • Based on your browser setting you may experience DASC files being saved in the Downloads folder on your computer, please make sure you check the Downloads folder if you do not see the file open in a new window or appear as a pop-up download.
