If you get an error code while downloading and installing Windows updates, the Update Troubleshooter can help resolve the problem.

Run the Windows update troubleshooter

If you are using a Windows 11 device, start by running the automated Windows Update troubleshooter in the Get Help app. It will automatically run diagnostics and attempt to fix most of the problems.

If the troubleshooter in Get Help app is unable to resolve your issue or If you are using an older version of Windows or a mobile device, please skip to General troubleshooting steps.

General troubleshooting

  • Select Start > Settings > System > Troubleshoot > Other troubleshooters.

  • Under Most frequent, select Run next to Windows Update.

  • Restart your device when the troubleshooter finishes.

  • Select Start > Settings > Windows Update > Check for updates, and then install any available updates.​​​​​​​

If the issue continues, run the troubleshooter again to check for additional errors, or see Troubleshoot problems updating Windowsand follow the troubleshooting steps.

If you get an error code while downloading and installing Windows updates, the Update Troubleshooter can help resolve the problem.

General troubleshooting

  • Restart your device when the troubleshooter finishes.

  • Select Start > Settings > Update & Security > Windows Update > Check for updates and then install any available updates.

If the issue continues, run the troubleshooter again to check for additional errors, or see Troubleshoot problems updating Windowsand follow the troubleshooting steps.
