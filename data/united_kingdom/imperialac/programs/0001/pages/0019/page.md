Apply online through [UCAS Hub](https://accounts.ucas.com/account/login).

You only need to submit one application to be considered for admission up to five different courses in the same year of entry:

- All five courses can be at different universities.
- There is no order of preference.
- If you are applying for medicine, dentistry, veterinary medicine or veterinary science, you can only apply for a maximum of four courses. Your fifth choice, if you use it, must be in a different subject.
- You can only submit one personal statement with your application. So it needs to cover all your course choices.

## Applying for multiple courses at Imperial

If you apply for multiple courses at Imperial, each counts as a separate choice on your application.

If you want to apply to multiple courses within the same Imperial department, we recommend that you speak to the department first for advice.

#### Have you checked if you need to take an admissions test as part of your application?

We use admissions tests for many of our undergraduate courses. The test you could need to take depends on which course you’re applying for. You can find out if you need to take an admissions test on the course page you are applying for. For more information about the admissions test we use and registration deadlines, visit the [Admissions test page](/study/apply/undergraduate/process/admissions-tests/).
