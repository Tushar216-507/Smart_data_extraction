You can download and install the Chrome web browser at no charge, and use it to browse the web.

## Check system requirements to use Chrome

Windows

To use Chrome on Windows with an Intel processor or ARM processor, you need:

- Intel processor:
  - Windows 10 and up.
  - Intel Pentium 4 processor or up that's SSE3 capable.
- ARM processor: Windows 11 and up.

Mac

To use Chrome on Mac, you'll need macOS 13 Ventura and up.

Linux

To use Chrome on Linux, you'll need:

- 64-bit Ubuntu 18.04+, Debian 10+, openSUSE 15.5+ or Fedora Linux 39+.
- x86-64 devices: An x86-64 processor that's SSE3 capable.
- ARM devices: 64-bit ARM CPUs.

## How to install Chrome

Important: Before you download, check if Chrome supports your operating system and you've met all other system requirements.

Windows

- On your computer, download the [installation file](https://www.google.com/chrome).
- To install the file, follow the on-screen instructions.
  - If you get the message 'Do you want to run this file?', select Run.
  - If you get the message 'Do you want to allow this app to make changes to your device?', select Yes.
- Open Chrome.

Mac

- On your computer, download the [installation file](https://www.google.com/chrome).
- Open the file named 'googlechrome.dmg'.
  - In the window that opens, you can find Chrome.
- Drag Chrome to the Applications folder.
  - You may have to enter the admin password.
  - If you can't enter the admin password, drag Chrome to a location where you have full permissions, such as your desktop.

Tip: To clean up after you install, in the Finder's sidebar, next to 'Chrome', select Eject .

To install Chrome, use the same software that installs programs on your computer. You must enter the administrator account password.

- On your computer, download the [installation file](https://www.google.com/chrome).

  - For Fedora/openSUSE: Select the x86-64 .rpm package or the arm64 .rpm package (for arm64 CPUs).
- To open the package, select Install.
