De esta forma, los enlaces se abrirán automáticamente en Chrome.

En algunos países, puede que se te pida que elijas un navegador predeterminado. Puedes cambiar tu navegador predeterminado en cualquier momento.

## Establecer Chrome como navegador web predeterminado

Importante: Si aún no tienes Google Chrome en tu ordenador, primero [descárgalo e instálalo](/chrome/answer/95346).

Windows 11

- En tu ordenador, selecciona Inicio .
- Selecciona Configuración Aplicaciones Aplicaciones predeterminadas.
- En "Establecer valores predeterminados para las aplicaciones", escribe

  ```
  Chrome
  ```

  en el cuadro de búsqueda.
- Selecciona Google Chrome.
- En la parte superior, junto a "Convertir a Google Chrome en el explorador predeterminado", selecciona Establecer como predeterminado.
  - Para asegurarte de que el cambio se haya aplicado a los tipos de archivo correctos, revisa la lista situada debajo de "Establecer tipos de archivo o de enlace predeterminados".

Para abrir Chrome fácilmente más adelante, añade un acceso directo a la barra de tareas. [Consulta cómo crear un acceso directo para Chrome](/chrome/answer/6204307#windows_shortcut).

Windows 10

- En tu ordenador, selecciona Inicio .
- Selecciona Configuración .
- Abre las aplicaciones predeterminadas:
  - Versión original: selecciona Sistema Aplicaciones predeterminadas.
  - Actualización de creadores: selecciona Aplicaciones Aplicaciones predeterminadas.
- En la sección "Explorador web" situada en la parte inferior, selecciona tu navegador actual.
- En la ventana "Elegir una aplicación", haz clic en Google Chrome.

Para abrir Chrome fácilmente más adelante, añade un acceso directo a la barra de tareas. [Consulta cómo crear un acceso directo para Chrome](/chrome/answer/6204307#windows_shortcut).

Mac

- En tu ordenador, abre Chrome.
- Arriba a la derecha, selecciona Más Configuración.
- En la sección "Navegador predeterminado", selecciona Elegir como predeterminado.
  - Si no ves el botón, significa que Chrome ya es tu navegador predeterminado.

Para abrir Chrome fácilmente más adelante, añade un acceso directo al Dock. [Consulta cómo crear un acceso directo para Chrome](/chrome/answer/6204307#mac_shortcut).

Linux

- En tu ordenador, abre Chrome.
- Arriba a la derecha, selecciona Más Configuración.
- En la sección "Navegador predeterminado", selecciona Elegir como predeterminado.
  - Si no ves el botón, significa que Chrome ya es tu navegador predeterminado.

Para abrir Chrome fácilmente más adelante, añade un acceso directo a la barra de tareas. [Consulta cómo crear un acceso directo para Chrome](/chrome/answer/6204307#linux_shortcut).
