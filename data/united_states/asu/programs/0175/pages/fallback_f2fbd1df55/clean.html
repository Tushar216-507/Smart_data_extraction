Chrome 웹브라우저를 무료로 다운로드하여 설치하고 웹을 탐색해 보세요.

Chrome 사용에 필요한 시스템 요구사항 확인하기

Windows

Intel 프로세서 또는 ARM 프로세서가 탑재된 Windows에서 Chrome을 사용하려면 다음이 필요합니다.

  • Intel 프로세서:
    • Windows 10 이상
    • Intel Pentium 4 프로세서 또는 SSE3을 지원하는 그 이상 버전
  • ARM 프로세서: Windows 11 이상

Mac

Mac에서 Chrome을 사용하려면 macOS 13 Ventura 이상이 필요합니다.

Linux

Linux에서 Chrome을 사용하려면 다음이 필요합니다.

  • 64비트 Ubuntu 18.04 이상, Debian 10 이상, openSUSE 15.5 이상 또는 Fedora Linux 39 이상
  • x86-64 기기: SSE3를 지원하는 x86-64 프로세서
  • ARM 기기: 64비트 ARM CPU

Chrome 설치 방법

중요: Chrome을 다운로드하기 전에 현재 사용 중인 운영체제에서 Chrome이 지원되는지 및 다른 모든 필수 시스템 요구사항을 충족하는지 확인하세요.

Windows

  • 컴퓨터에 설치 파일을 다운로드합니다.
  • 파일을 설치하려면 화면에 표시된 안내를 따릅니다.
    • '이 파일을 실행하시겠습니까?'라는 메시지가 표시되면 실행을 선택합니다.
    • '이 앱에서 기기를 변경할 수 있도록 허용하시겠습니까?'라는 메시지가 표시되면 예를 선택합니다.
  • Chrome을 엽니다.
    • Windows 10 이상의 경우 설치가 완료되면 Chrome 창이 열립니다. Chrome을 기본 브라우저로 지정할 수 있습니다.
  • Windows 10 이상의 경우 설치가 완료되면 Chrome 창이 열립니다.

도움말: Firefox와 같은 다른 브라우저를 사용한 경우 Chrome으로 설정을 가져올 수 있습니다.

Windows 컴퓨터에 Chrome을 다운로드할 때 문제가 있는 경우 대체 링크를 사용하여 다른 컴퓨터에 Chrome을 다운로드하세요.

  • 컴퓨터에 다른 컴퓨터용 Chrome 설치 프로그램을 다운로드합니다.
  • 페이지 하단의 'Chrome 제품군'에서 기타 플랫폼을 선택합니다.
  • Chrome을 설치할 기기의 OS를 선택합니다.
  • 파일을 다운로드합니다.
  • Chrome을 설치하려는 컴퓨터로 파일을 이동합니다.
  • 화면에 표시된 안내를 따라 설치합니다.

Mac

  • 컴퓨터에 설치 파일을 다운로드합니다.
  • 'googlechrome.dmg' 파일을 엽니다.
    • 창이 열리면 Chrome을 찾을 수 있습니다.
  • Chrome을 애플리케이션 폴더로 드래그합니다.
    • 관리자 비밀번호를 입력해야 할 수도 있습니다.
    • 관리자 비밀번호를 입력할 수 없는 경우 Chrome을 바탕화면과 같이 모든 권한이 있는 위치로 드래그합니다.

도움말: 설치 후 정리하려면 Finder의 사이드바에서 'Chrome' 옆에 있는 꺼내기 를 선택합니다.

Linux

Linux에 Chrome 설치 및 사용하기

Chrome을 설치하려면 컴퓨터에 프로그램을 설치할 때와 동일한 소프트웨어를 사용하세요. 관리자 계정 비밀번호를 입력해야 합니다.

  • 컴퓨터에 설치 파일을 다운로드합니다.
    • Debian/Ubuntu: x86-64 .deb 패키지 또는 arm64 .deb 패키지 (arm64 CPU용)를 선택합니다.
    • Fedora/openSUSE: x86-64 .rpm 패키지 또는 arm64 .rpm 패키지 (arm64 CPU용)를 선택합니다.
  • 패키지를 열려면 설치 를 선택합니다.
  • 관리자 비밀번호를 입력합니다.
    • Chrome을 처음 실행할 때는 Google 서비스 약관을 검토하고 동의해야 합니다.
